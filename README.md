# AP Psychology 12: Stroop Effect Research Project

**Live Interactive Demo:** [Click here to run the Stroop Test](https://oraclezzzn.github.io/Stroop-Effect-Test/)

## Project Overview
This repository hosts the browser-based testing application for our AP Psychology 12 research project. The study measures **Stroop Interference** (the delay in reaction time when processing conflicting stimuli) to investigate the cognitive mechanisms behind the **Bilingual Advantage Hypothesis**. 

Specifically, this test is designed to compare the interference scores (in milliseconds) of native English speakers against recent English Language Learners (ELL) to observe how varying levels of language mastery and automatic reading responses impact cognitive control.

## Ethical Guidelines & Data Privacy
**This hosted version is a front-end demonstration only.** 

To protect participant confidentiality:
* **No data is collected, stored, or transmitted.** 
* The application runs entirely locally in your web browser's memory. 
* Once the browser tab is closed or refreshed, all temporary session data is permanently erased.

## Researcher Tools (For Evaluation)
At the end of the test, evaluators can press the **`S`** key on their keyboard to reveal the hidden **Researcher Panel**. 

This panel calculates and displays the live Stroop Interference Score for the current session, similar to what we see when we are actually parsing the data.
